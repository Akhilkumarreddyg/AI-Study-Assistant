# 📚 AI Study Assistant

An AI-powered study assistant built using **Python, Streamlit, LangChain, LangGraph, and Ollama (Llama 3.2)**.

This application helps students understand technical topics by providing simple explanations, important points, and examples using a locally running Large Language Model (LLM).

## 🚀 Project Overview

The AI Study Assistant allows students to enter any topic or question and receive an easy-to-understand explanation generated by AI.

It uses Ollama to run the Llama 3.2 model locally, LangChain to interact with the language model, and LangGraph to manage the workflow.

## ✨ Features

- Enter any topic or question.
- Get simple and beginner-friendly explanations.
- Generate important points.
- Understand topics with examples.
- Run the LLM locally using Ollama.
- Simple and interactive Streamlit interface.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Akhilkumarreddyg/AI-Study-Assistant.git
```

### 2. Navigate to the project folder

```bash
cd AI-Study-Assistant
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

Windows:

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Install and configure Ollama

Download Ollama from:

https://ollama.com/

Pull the Llama 3.2 model:

```bash
ollama pull llama3.2
```

### 7. Run the application

```bash
streamlit run app.py
```

The application will open in your browser, usually at:

```text
http://localhost:8501
```

## 🔄 Application Workflow

1. Student enters a question or topic.
2. Streamlit receives the input.
3. LangGraph manages the study assistant workflow.
4. LangChain sends the prompt to the Llama 3.2 model through Ollama.
5. The model generates the explanation.
6. Streamlit displays the AI-generated answer.
